# YouTube Shorts Content and Production Standard
**YouTube Agentic AI Studio (YAAS)**  
**Channel:** Stories Malik

## 1. Editorial Vision: Dedicated Shorts Storytelling

A YouTube Short on Stories Malik is **not** a lazy cut from a long video. Each Short is an independently conceived, high-retention 25–60 second historical insight with a complete narrative arc: immediate intrigue, historical substance, and a satisfying payoff.

---

## 2. The 4-Part High-Retention Shorts Structure

```
[0 – 2 Seconds] The Immediate Hook
Surprising verified fact, visual anomaly, or historical paradox.
Example: "क्या आप जानते हैं कि महाराणा प्रताप के घोड़े चेतक ने युद्ध में हाथी की नकली सूंड क्यों पहनी थी?"
   ▼
[2 – 10 Seconds] The Context
Why this historical situation mattered. The high stakes or setting.
   ▼
[10 – 40 Seconds] The Core Revelation & Conflict
The strategic tactical move, archaeological discovery, or inscriptional revelation.
   ▼
[Final 5 – 10 Seconds] The Payoff & Organic Channel Connection
The satisfying resolution, followed by an organic invitation to explore the full documentary on Stories Malik.
```

---

## 3. Supported Shorts Formats

The Shorts engine supports 8 specialized documentary micro-formats:

1. **`historical_fact`:** Surprising, verifiable historical facts that challenge common assumptions.
2. **`mystery_investigation`:** Unresolved ancient mysteries (e.g. undeciphered Indus script, vanishing of Kuldhara).
3. **`forgotten_personality`:** Unsung heroes, tacticians, and queens (Rani Durgavati, Sangrama Vijayottunggavarman).
4. **`battle_strategy`:** Military tactical masterstrokes (Aravalli mountain pass ambushes, Chola naval tactics).
5. **`ancient_engineering`:** Ancient architectural marvels (Kailash Temple top-down carving, rustless iron pillar).
6. **`misconception_debunked`:** Debunking popular colonial or modern myths using ASI/archaeological evidence.
7. **`archaeological_discovery`:** Marine archaeology at Dwarka, submerged Khambhat ruins, Keezhadi pottery graffiti.
8. **`longform_teaser`:** Narrative teaser that directly links to a full 8–13 minute documentary on Stories Malik.

## 4. Mobile Safe-Area Framing (9:16 Vertical)

All captions, subtitles, and key visual elements must strictly remain within YouTube's mobile interface safe zones:

```
+------------------------------------------+
| Top 15%: YouTube Header / Search Overlay |  <- KEEP CLEAR OF IMPORTANT TEXT
+------------------------------------------+
|                                          |
|                                          |
|        CENTRAL 70% SAFE ZONE             |
|   (Captions, Main Visual Focal Point)    |
|                                          |
|                                          |
+------------------------------------------+
| Right 18%: Like, Comment, Share, Sound   |  <- KEEP RIGHT MARGIN PADDED
+------------------------------------------+
| Bottom 15%: Title, Channel Icon, Music   |  <- KEEP SUBTITLES ABOVE BOTTOM 15%
+------------------------------------------+
```

* **Resolution:** 1080×1920 (9:16 vertical).
* **Subtitle Position:** Centered horizontally at `Y = 70%` (above the bottom channel info bar).
* **Subtitle Font Size:** Responsive 48–56pt bold with semi-transparent dark backing pill for high contrast against dynamic backgrounds.
